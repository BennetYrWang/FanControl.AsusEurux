# Support

Open EURUX detection, RPM reporting, PWM control, firmware compatibility, packaging, and plugin
installation issues in this repository. Please use the bug-report form and remove USB serial
numbers or unrelated machine details from logs.

Use the upstream [FanControl repository](https://github.com/Rem0o/FanControl.Releases) only for
FanControl application behavior that is independent of this plugin, such as UI problems or general
curve behavior. FanControl's maintainers explicitly ask hardware-specific integrations to handle
their own support.

This is a volunteer, unofficial project with no warranty. For a potentially unsafe control state,
disable the EURUX controls, exit FanControl, and restore a known-good configuration in Armoury Crate
before collecting more diagnostics.
